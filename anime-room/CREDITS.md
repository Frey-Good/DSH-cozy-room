- 项目：https://github.com/PC2005-cloud/dsh-pet
- 作者：PC2005-cloud
- 许可说明（摘自其 README）：**代码 MIT；素材禁止商用；二创在公开渠道须注明出处（附上上面的链接）**

这些动画是 dsh-pet 作者的作品，本仓库只做「在 3D 房间里播放」的集成，不主张对动画素材的版权。

## 公开到 GitHub 时请注意

1. **保留出处**：README / 本文件里保留 dsh-pet 的链接与作者名
2. **不要商用**：不要把这些素材放进付费产品、付费壁纸包或带广告的分发
3. **最稳妥**：不把 `assets/webm/` 与 `js/pet-videos.js` 提交进仓库（加进 `.gitignore`），改成让使用者自己从 dsh-pet 复制；仓库只放代码和程序化贴图
4. 如果拿不准，直接去 dsh-pet 仓库开 issue 问作者授权
