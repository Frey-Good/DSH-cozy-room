# Changelog

## 1.3.0 — 2026-11-13

### 新增

- **动作库扩到 284 段**：接入 aboutme-pets 的 162 段蓝毛小女仆动作；空闲时从整个动作库随机挑（看书/扫地/浇水/看手机除外）
- **看书**：开始 → 循环 → 结束三段式；看书时工作不打断、默认不理消息，连发两条会放下书；30 分钟自动合书
- **工作姿势循环**：code → busy → think 轮换，成功才雀跃，出错吓一跳
- **床上躺刷手机 / 躺睡觉**：无床垫素材，睡前先刷 18 秒手机再睡着；床上发消息会侧躺着回
- **浇水新版**：花洒水雾、空中消散、固定锚点不漂移、一次浇完所有蔫花并真正恢复绿色
- **家具落灰**：用「擦桌碎碎念」擦掉，不再只有扫地
- **设置面板**：新增接入大模型 / 碎碎念 / 随机动作库 / 自己打扫 / 房间会变旧 5 个开关；点空白收起；内容多时内部滚动

### 改进

- 聊天先回执再处理：睡着/看书时不再出现「假回复」
- 回复等到手机动画播完才落地（站着约 7 秒，床上约 9 秒），期间显示「正在输入」
- 睡着默认不回消息；白天工作会叫醒，深夜不会
- 睡满 9 小时自动起床，不再一睡一整天

### 修复

- 刷新后所有语音指令只回台词不执行（handlers 只在 save 里注册）
- 说「看书/睡觉」被看手机动作覆盖
- 刷新后睡觉状态丢失
- idle 状态轮询会叫醒午睡
- 植物浇水后颜色回不来（共享原色缓存被污染）
- 家具 uid 每次刷新重新生成，导致浇花对不上号
- 夜里晴天说「出太阳」
- 身份重建后 `/self` 没有名字；静态资源路径正斜杠 403

## 1.2.0 — 2026-11-10

### 新增

- **记忆流**：第一人称记录聊天、打扫、睡觉、天气、滑倒等事件；重复的事权重会涨，长期不提会衰减（越重要衰减越慢）
- **反思**：每 24 小时把记忆压成新的 `self.md`（我是谁 / 最想要 / 想要 / 最讨厌 / 讨厌 / 喜欢）
- **她的自我页** `/self`：生日、星座、生肖、八字、初始倾向、喜欢/讨厌/想要、现在的她、她认识的 ta
- **日记页** `/diary`：只读记忆流，按天分组、可搜索、可导出
- **数据页** `/data`：导出备份；三档重置（房间 / 记忆 / 完全重来）
- **出生身份**：安装当天（或自定义生日）用星座/生肖/八字生成初始性格；一次模型调用，结果存 `identity.json`
- **改名**：聊天里说「你以后叫 XX」即可
- **她对 ta 的了解** `user.md`：反思时同时更新，带她自己的判断
- **聊天指令**：睡觉 / 打扫 / 浇水 / 喂猫 / 铺床，带叛逆值，可以拒绝你
- **睡觉规则**：23:00–08:00 不被工作吵醒；白天工作需要会醒；睡着默认不回消息
- **头顶气泡也走模型** `/quip`：限 20 字，12 秒限流，失败回落固定台词
- **打扫动作**：扫地 A / B（镜像）/ D，浇水 A（旧版）
- **落灰/擦亮**：灰印淡出 + 星星 + 地板亮一下

### 改进

- 聊天一律走模型（含指令回应），超时/失败才用规则兜底
- 指令无事可做时如实说（“现在挺干净的”），不再假装打扫
- 一次性修复：恢复被旧“布置”功能覆盖的房间布局

### 已知问题

- 需要透明主题才能看到房间
- 扫地 B 是镜像、D 只有 3 秒
- 浇水动作还是柱状水（新版未接入）
- 手机聊天记录不包含在备份里
- 没配模型时回复比较规矩
